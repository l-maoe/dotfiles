# My personal dotfiles

feel free to use, i guess. This is not optimized for laptops because I couldn't be bothered. Will also most likely not work out of the box especially with niri's configuration. Also change the defaulticon.jpg in the dunst folder if you'd like

## Fonts required
- [Maple Mono](https://github.com/subframe7536/maple-font)
- [Fira Code Two iScript](https://github.com/willstocks/FiraCode2iScript)
- Some noto fonts

## Icons required
- [BeautyLine](https://www.gnome-look.org/p/1425426/)

## Applications required
- btop
- dunst
- fastfetch
- fuzzel
- helix
- kitty
- niri
- swaylock-effects
- waybar
- wlogout
- pulseaudio
- pipewire + wireplumber
- wl-gammarelay
- playerctl
- awww
- lxqt-policykit
- pavucontrol
- mpris
- possibly some other stuff I forgot about

In Niri you can see the most important hotkeys by pressing Mod+Shift+M
